# Salba Isaia — Portfolio

A responsive personal portfolio website built with HTML, CSS and vanilla JavaScript. Designed to deploy to GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Deploy
This repository includes a GitHub Actions workflow that deploys the site to GitHub Pages when changes are pushed to `main`. In your repository, go to **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.

## Personalize
Update the email address, GitHub links, project information, profile text and skills in `index.html`. Styling lives in `assets/css/style.css`.
